# International-Coastal-Cleanup-26
Swachh Sagar, Surakshit Sagar 5.0 (Clean Coast, Safe Sea) (SSSS 5.0) is India’s flagship national coastal cleanliness and ocean conservation campaign led by the Ministry of Earth Sciences (MoES) in mission-mode partnership with the Indian Coast Guard, NIOT, INCOIS, and coastal state administrations.
